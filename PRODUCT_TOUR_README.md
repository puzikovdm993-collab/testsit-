# Product Tour (Онбординг) - Документация

## Обзор

Модуль `productTour.js` реализует интерактивный тур по интерфейсу приложения WTIS для новых пользователей.

## Функционал

### Автоматический запуск
- Тур автоматически запускается при первом посещении страницы
- Статус прохождения сохраняется в `localStorage`
- После завершения тур больше не запускается автоматически

### Ручной запуск
- Кнопка "Запустить онбординг" в модальном окне помощи
- Вызов через консоль: `productTour.start()`

### Навигация
- **Далее** → - переход к следующему шагу
- **← Назад** - возврат к предыдущему шагу
- **Завершить** - завершение тура на последнем шаге
- **×** - досрочное завершение тура

## API

```javascript
// Запустить тур
productTour.start()

// Завершить тур (с отметкой о прохождении)
productTour.finish()

// Завершить тур (без отметки)
productTour.end()

// Следующий шаг
productTour.next()

// Предыдущий шаг
productTour.prev()

// Проверить, пройден ли тур
productTour.isTourCompleted() // true/false

// Сбросить статус прохождения
productTour.resetTour()

// Текущий шаг
productTour.getCurrentStep() // номер шага

// Всего шагов
productTour.getTotalSteps() // количество

// Активен ли тур
productTour.isActive() // true/false
```

## Структура шагов

Каждый шаг тура содержит:
- `id` - селектор элемента (ID, класс, data-атрибут)
- `title` - заголовок подсказки
- `description` - описание функционала
- `position` - позиция подсказки (top, bottom, left, right)

## Шаги тура

1. Вкладка "Файл" - управление файлами
2. Вкладка "Правка" - отмена/повтор действий
3. Вкладка "Вид" - масштабирование
4. Вкладка "Изображение" - геометрические преобразования
5. Вкладка "Фильтры" - фильтры и обработка
6. Вкладка "Регулировка" - настройка параметров
7. Вкладка "Инструменты" - специализированные инструменты
8. Вкладка "Режимы" - workflow режимы
9. Вкладка "Настройки" - параметры приложения
10. Кнопка "Помощь" - справочная информация
11. Панель инструментов - основные инструменты
12. Рабочая область - холст для работы

## Стилизация

CSS стили добавляются динамически при запуске тура:
- `.tour-highlighted` - подсветка текущего элемента
- `.tour-tooltip` - контейнер подсказки
- `.tour-active` - режим активного тура

## Файлы

- `/src/ui/productTour.js` - основной модуль тура
- `/index.html` - подключён скрипт и добавлена кнопка запуска

## Управление состоянием

```javascript
// Очистить localStorage и запустить тур заново
localStorage.removeItem('productTourCompleted');
productTour.start();

// Или использовать API
productTour.resetTour();
productTour.start();
```

## Особенности

- Адаптивная вёрстка для мобильных устройств
- Поддержка тёмной и светлой темы
- Плавные анимации появления
- Автоматическая прокрутка к элементам
- Защита от выхода за границы экрана
