# Руководство по работе с WTIS API

Это практическое руководство о том, как сервер взаимодействует с клиентом. Представьте себе сервер как помощника в лаборатории, который может работать с файлами на компьютере и в облачном хранилище.

## Основы работы

Сервер создан на Python (Flask). Вся сложная обработка данных (фильтры, графики) происходит в браузере пользователя, а сервер занимается тем, что хранит и передает файлы.

**Основной адрес:** `http://localhost:5000`  
**Формат данных:** JSON, изображения передаются бинарным потоком.

---

## 1. Работа с файлами на сервере

Сервер управляет папкой `uploads/`, где временно хранятся загруженные файлы.

### Посмотреть список файлов
Получить список всех изображений и данных на сервере.

- **Адрес:** `GET /images`
- **Результат:** Список имен файлов.
  ```json
  ["scan_01.png", "result_matrix.tpt", "photo.jpg"]
  ```

### Загрузить файл
Поместить файл на сервер.

- **Адрес:** `POST /upload`
- **Данные:** Поле `file` с изображением (PNG, JPG, TPT).
- **Ответ:** Подтверждение загрузки и новое имя файла.

### Скачать файл
Получить файл, который находится на сервере.

- **Адрес:** `GET /image/<имя_файла>`
- **Пример:** `GET /image/scan_01.png`
- **Результат:** Файл, который можно открыть или сохранить.

### Удалить файл
Убрать файл с сервера.

- **Адрес:** `DELETE /delete/<имя_файла>`
- **Ответ:** Подтверждение удаления.

## 2. Работа с облачным хранилищем (MinIO)

Интерфейс для работы с надежным облачным хранилищем, где хранятся важные данные. Сервер выступает посредником между вами и облаком.

> **Важно:** Настройки подключения к облаку находятся на сервере, вам их указывать не нужно.

### Посмотреть содержимое облака
Получить список файлов в облаке.

- **Адрес:** `GET /list_minio`
- **Результат:** Список файлов с размерами и датами.

### Сохранить в облако
Загрузить файл в долговременное хранение.

- **Адрес:** `POST /upload_minio`
- **Данные:** JSON с полями:
  1. `object_name`: Имя файла в облаке (например, `project1/data.json`).
  2. `data`: Содержимое файла в формате Base64.
  3. `content_type`: Тип данных (необязательно).
- **Результат:** Файл сохранен в облаке.

### Скачать из облака
Получить файл из облака.

- **Адрес:** `GET /download_minio/<путь_к_файлу>`
- **Пример:** `GET /download_minio/experiments/2023/october/results.json`
- **Результат:** Файл скачивается.

### Создать папку
Создать виртуальную папку в облаке.

- **Адрес:** `POST /mkdir_minio`
- **Данные:** JSON с именем папки (обязательно заканчивать на `/`).
  ```json
  { "folder_name": "new_experiment/" }
  ```

### Удалить из облака
Удалить файл из облака.

- **Адрес:** `DELETE /delete_minio`
- **Данные:** JSON с именем файла.
  ```json
  { "object_name": "old_data/temp_result.json" }
  ```

---

## Что сервер НЕ делает

Сервер не обрабатывает изображения и не строит графики. Вся обработка происходит в браузере, на вашем компьютере. Это позволяет серверу работать быстро и обслуживать много пользователей.

---

## Ошибки

| Код | Описание | Пояснение |
|-----|----------|-----------|
| **200** | OK | Все хорошо, запрос выполнен успешно. |
| **400** | Bad Request | Неправильные данные в запросе (например, нет файла). |
| **404** | Not Found | Файл не найден ни на сервере, ни в облаке. |
| **500** | Internal Server Error | Ошибка на стороне сервера или проблема с подключением к облаку. |

## Примеры команд (cURL)

Вы можете использовать эти команды в терминале для проверки работы API.

**Загрузить картинку на сервер:**
```bash
curl -F "file=@my_scan.png" http://localhost:5000/upload
```

**Посмотреть список файлов на сервере:**
```bash
curl http://localhost:5000/images
```

**Скачать файл с сервера:**
```bash
curl -O http://localhost:5000/image/my_scan.png
```

**Посмотреть содержимое облака:**
```bash
curl http://localhost:5000/list_minio
```

**Удалить файл с сервера:**
```bash
curl -X DELETE http://localhost:5000/delete/my_scan.png
```

**Скачать файл из облака:**
```bash
curl -O http://localhost:5000/download_minio/reports/final_result.json
```

**Создать папку в облаке:**
```bash
curl -X POST -H "Content-Type: application/json" \
  -d '{"folder_name": "new_project/"}' \
  http://localhost:5000/mkdir_minio
```

**Удалить файл из облака:**
```bash
curl -X DELETE -H "Content-Type: application/json" \
  -d '{"object_name": "old_data/temp.json"}' \
  http://localhost:5000/delete_minio
```
