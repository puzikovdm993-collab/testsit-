# Анализ репозитория WTIS (Web-based Tomograph Instrumental System)

## 📋 Общая информация

**WTIS** — это веб-приложение для обработки, анализа и визуализации рентгеновских изображений. Предназначено для работы с матричными данными томографических исследований.

| Параметр | Значение |
|----------|----------|
| **Основной язык** | JavaScript (ES6+) + Python |
| **Фреймворк** | Flask (backend) |
| **Общий объём кода** | ~23 200 строк |
| **Структура** | Модульная архитектура |
| **Git-статус** | 1 коммит, ветка `main` |

## 🎯 Ключевые возможности

1. **Загрузка и отображение** изображений (PNG, JPG, TPT форматы)
2. **Полиномиальная аппроксимация** поверхностей методом наименьших квадратов
3. **Фильтры обработки**:
   - Медианный, Собеля, пороговый, логарифмический
   - Выделение контуров (edge detection)
4. **Цветовое картирование** (colormaps: hot, jet, gray, viridis, plasma, coolwarm)
5. **Инструменты выделения**:
   - Прямоугольное выделение
   - Лассо (свободная форма)
6. **Многооконный интерфейс** - работа с несколькими файлами одновременно
7. **История действий** - отмена/повтор до 50 операций (Ctrl+Z, Ctrl+Y)
8. **Интеграция с MinIO** - загрузка/выгрузка матричных данных

## 🌐 API Endpoints (Backend)

### Работа с изображениями

| Метод | Endpoint | Описание |
|-------|----------|----------|
| GET | `/` | Главная страница |
| GET | `/list_local` | Список локальных изображений |
| POST | `/upload` | Загрузка изображения |
| DELETE | `/delete/<filename>` | Удаление изображения |

### Работа с MinIO

| Метод | Endpoint | Описание |
|-------|----------|----------|
| GET | `/list_minio` | Список объектов в бакете |
| POST | `/upload_minio` | Загрузка матрицы (JSON + base64) |
| GET | `/download_minio/<object>` | Скачивание из MinIO |
| POST | `/mkdir_minio` | Создание папки |
| DELETE | `/delete_minio` | Удаление объекта |
| POST | `/move` | Перемещение объекта |

## ⚙️ Конфигурация

Для работы требуется `.env` файл с параметрами:

```bash
MINIO_ENDPOINT=localhost:9000
MINIO_ACCESS_KEY=minioadmin
MINIO_SECRET_KEY=minioadmin
MINIO_BUCKET=wtis
MINIO_REGION=us-east-1
MINIO_SECURE=false
```

**Запуск приложения:**
```bash
python app.py
```
Приложение доступно по адресу: `http://localhost:15404`

## 📝 Примечания

- Проект использует **модульную архитектуру** с разделением ответственности
- Реализована поддержка **отмены/повтора действий** через историю состояний
- Данные в MinIO хранятся в формате **JSON + base64** кодирование матриц
- Интерфейс выполнен в стиле **ленточных редакторов** (ribbon UI)
- Приложение поддерживает работу как с **локальными файлами**, так и с **облачным хранилищем**
